四、四页视觉回归（1440×900，≤1px）—— 结果：四页 0px Δ0

新旧 CSS 四页逐像素差异 0px、Δ0；同版本对照（新 CSS 连渲两遍）同样 0px、Δ0——环境噪声底为零，0px 结论无侥幸空间。
方法论展开（每处差异源都有明确成因与对策）
  1. 双栈各登记本 pass 的 CSS——起栈前把该 pass 的 CSS 放上磁盘，登记指纹与磁盘自洽，避免「实测≠登记」警告块污染画面；
  2. 夹具手术——登记产物从 app-base.css（本轮被改、新旧哈希必不同）换成 app.js（本轮未改、逐字节一致），文件页/预览抽屉/核对行指纹、大小、原文全部同源；页面走的仍是真实登记+真实物理文件读取链路；
  3. 时间归一——任务 JSON 全部 ISO 时间戳平移到共同基准 T0，页面时钟冻结到同一绝对时刻（T0+2min），两 pass 时间文本逐字相同；
  4. 状态归零——每 pass 清 localStorage、禁网络缓存、独立栈隔离服务端内存态。
辅助诊断：计算样式逐串探针（新旧完全相同→排除变量舍入）、差异像素坐标谱（9px 等距×单通道 ±1 → 亚像素抗锯齿特征，同版本对照证实为一次性光栅抖动）。
