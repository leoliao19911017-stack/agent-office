二、本轮改动（只动 F02 范围）

产品代码 · web/preview.js 三处 （备份 web/preview.js.bak-f02r4，27074 B，node --check 通过，其余模块零改动）

  1. fetch(u, { cache:'no-store' })（~:91）：快照留档可在服务端被删改，同一 URL 不得复用 HTTP 缓存旧成功响应——堵「删了快照还显示旧成功」的缓存污染冒充路径。
  2. if (!savedOk && !sv)（~:100）：服务端端点已明确回答即以其结论为准；仅端点不在/请求失败（旧服务进程）才退回页内候选核对——堵「页内 flow 副本滞后把明确失败翻回成功展示」的冒充路径。
  3. 不可用态「保存原文」行改服务端实测优先（~:125-135）：有候选核对不上 →「有快照留档但核对不上：快照 N B · 指纹 xxx ≠ 登记版本（服务端实测）」；无候选 →「未保存——服务端实测该登记已无保存原文或快照留档」。页内旧副本不算数。
