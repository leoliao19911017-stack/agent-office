# 02 澄清记录

## Hermes 问

Q1 是删除还是归档？
Q2 谁能删？
Q3 要不要批量？
Q4 正在跑的任务能删吗？

## Leo 答

「可以批量删，归档，恢复，正在跑的不能删需要先停」

## 提取出的规则

| 项 | 结论 |
|---|---|
| 批量 | ✅ 支持多选批量 |
| 删除 | ✅ 可以删（不只是归档） |
| 归档 | ✅ 有归档 |
| 恢复 | ✅ 归档可恢复 |
| running 任务 | ❌ 不能删，必须先停 |

## 遗留未澄清（走合理默认，实现时说明）

- 归档和删除的区别：归档=可恢复，删除=不可恢复
- 真删除要不要二次确认：要（防误删）
- 归档区在哪：列表底部入口
- 谁能删：看板无权限系统，就是 Leo 本人使用
