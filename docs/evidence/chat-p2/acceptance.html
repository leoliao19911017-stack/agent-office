关于 POST /api/tasks/:id/finish

任务要求用它把每批登记成 completed，但仓库里原本没有这个端点（只有 attempt / checkpoint / handoff），P1 那条所以停在 unknown。 本批补上了：它不直接写 completed（状态机硬规矩「completed 必须绑定验收通过」），而是做三件事——把执行实例正常结束（completed/done）、 记一条必须带证据的 acceptance_passed（没有 evidence 直接 400 EVIDENCE_REQUIRED）、让状态机自己算出 completed。 带 command 时证据来源记 verifier（脚本验的），否则记 user（人工验收）。
